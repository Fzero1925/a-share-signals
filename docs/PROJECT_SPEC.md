# A股模拟盘回测系统 — 项目总规范

## 1. 项目目标

构建一个 **纯本地运行的Web应用**，用于：
- **策略回测**：在历史数据上验证交易策略的收益和风险
- **模拟盘交易**：策略每日生成买卖信号，按真实行情追踪虚拟持仓盈亏
- **多策略对比**：同时运行多套策略，横向比较表现

**核心价值**：在不投入真金白银的情况下，验证策略是否"能赚钱"。

## 2. 用户画像

- 个人散户投资者
- 无编程背景（界面操作，非命令行）
- 空仓观望中，想找到适合自己的交易风格
- 短期追求准确性，长期缺乏经验

## 3. 技术约束（不可妥协）

| 约束项 | 要求 |
|--------|------|
| 运行环境 | Windows 本地，Python 3.10+ |
| 硬件 | 无 GPU，普通笔记本即可 |
| 数据源 | 免费（AKShare），备用：Tushare免费版 |
| 网络 | 需要联网拉数据，其余离线可用 |
| 部署 | `streamlit run app.py` 一键启动，浏览器访问 localhost:8501 |
| AI API | 可选接入，不依赖，用于增强信号解读 |

## 4. 技术栈

### 5.4 Phase 4 vectorbt 向量化（已列入计划，暂缓）

**目的**：向量化回测，支持更大参数网格（如 50+ 组组合秒级完成），参数热力图更精细。

**风险（评估后决定暂缓）**：
1. **CI 依赖风险（主要）**：vectorbt 依赖 numba，GitHub Actions 云端 `pip install` 可能因版本兼容失败，导致每日定时任务整体挂掉；安装耗时 2-3 分钟，挤压 15 分钟任务时限
2. **本地/CI 环境差异**：Windows 本地能装 ≠ Ubuntu CI 能装，增加维护成本
3. **当前已够用**：现有引擎已优化至 3-5 秒/次（numpy 向量化），24 组参数约 2 分钟，满足散户验证需求

**启用条件**：当需要大规模参数优化（>50 组）或因子挖掘时，先在 CI 环境单独验证 vectorbt 安装成功后再引入。

## 6. A股特有规则（必须遵守）

| 规则 | 回测中的实现 |
|------|-------------|
| T+1交易 | 当日买入，次日才能卖出 |
| 涨跌停限制 | 涨停(10%/20%)无法买入，跌停无法卖出 |
| 交易费用 | 印花税0.1%（卖出），佣金0.03%（买卖），过户费0.002% |
| 最小交易单位 | 100股（1手） |
| 交易时间 | 9:30-11:30, 13:00-15:00 |
| 科创板/创业板 | 688/300开头，涨跌幅20% |

## 7. 非功能需求

- 每个页面加载不超过3秒（含数据拉取）
- 回测10年数据（约2500个交易日）应在30秒内完成
- 所有文件编码UTF-8
- 代码不加注释（由文档说明），变量/函数名自解释
- 错误处理：数据拉取失败时有友好提示，不崩溃

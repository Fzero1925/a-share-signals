# Streamlit UI 界面规范

## 通用设计原则

- 主题：深色模式为首选（量化终端风格），可选浅色
- 布局：侧边栏 = 全局控制，主区域 = 内容展示
- 颜色语义：绿涨红跌（A股习惯），买入标记绿色箭头，卖出标记红色箭头
- 字体：中文友好，数据表格等宽字体

### K线图要求 (Plotly)
```python
import plotly.graph_objects as go

fig = go.Figure()
fig.add_trace(go.Candlestick(
    x=df['date'],
    open=df['open'], high=df['high'],
    low=df['low'], close=df['close'],
    name='K线',
    increasing_line_color='red',      # A股习惯红涨绿跌
    decreasing_line_color='green',
))
# 叠加均线
fig.add_trace(go.Scatter(x=df['date'], y=df['ma5'], name='MA5', line=dict(color='orange', width=1)))
# 成交量在副图
fig.add_trace(go.Bar(x=df['date'], y=df['volume'], name='成交量', yaxis='y2'))
```

### 股票代码输入
- 支持6位数字简码
- 支持股票名称模糊搜索（输入"平安"出现000001 平安银行）
- 支持拼音首字母搜索（输入"payh"出现平安银行）

## Streamlit 页面注册 (`app.py`)

```python
import streamlit as st

st.set_page_config(
    page_title="A股模拟盘回测系统",
    page_icon="📈",
    layout="wide",
    initial_sidebar_state="expanded",
)

# 侧边栏导航
page = st.sidebar.radio(
    "导航",
    ["数据浏览", "策略回测", "模拟盘交易", "策略对比"],
)

if page == "数据浏览":
    from ui.page_data import show
    show()
elif page == "策略回测":
    from ui.page_backtest import show
    show()
elif page == "模拟盘交易":
    from ui.page_paper_trading import show
    show()
elif page == "策略对比":
    from ui.page_compare import show
    show()
```

## 注意事项

1. **所有页面函数签名必须是 `def show():`**，不传参数，用 `st.session_state` 共享状态
2. **数据加载用 `@st.cache_data`** 装饰器缓存，避免重复拉取
3. **长时间操作用 `st.spinner()`** 显示加载状态
4. **错误用 `st.error()`** 显示，不抛异常到界面
5. **中文标签全部UTF-8**，文件首行加 `# -*- coding: utf-8 -*-`
